# RehearsePrompt 종합 사용자 설명서 (User Guide)

**RehearsePrompt**는 모의 면접 준비, 프레젠테이션 발표 연습, 영상 콘텐츠 촬영 시 카메라를 응시하며 자연스러운 시선과 속도로 말할 수 있도록 도와주는 전문 텔레프롬프터 데스크톱 애플리케이션입니다.

## 1. 앱 소개 및 올바른 사용 안내

![앱 메인 화면 및 대본 목록](images/guide-main-overview.png)

### 앱의 목적
- 면접 예상 질문에 대한 핵심 답변을 체계적으로 구조화하고 실전처럼 연습합니다.
- 발표 대본을 읽을 때 너무 빠르거나 느려지지 않도록 최적의 말하기 호흡(WPM)을 훈련합니다.
- 카메라 렌즈 바로 아래에 대본을 배치하여 시선이 아래로 떨어지지 않고 면접관을 바라보도록 자세를 교정합니다.

### 적합한 사용 사례 (권장)
- 온라인 모의 면접 및 화상 발표 전 사전 리허설
- YouTube, 온라인 강의, 자기소개 영상 촬영 시 대본 리딩
- 1분 자기소개, 프로젝트 경험 설명 등 핵심 말하기 연습
- 카메라를 똑바로 보면서 자연스럽게 생각을 전달하는 시선 훈련

### 적합하지 않은 사용 사례 (주의)
- 실제 온라인 채용 면접이나 공인 시험 감독 시스템에서 규정을 어기고 몰래 대본을 훔쳐보는 행위
- 시험 부정행위나 감시 우회 목적으로의 부적절한 오용

### 데이터 저장 위치 및 개인정보 보호
- **100% 로컬 저장**: 작성하신 모든 대본과 설정값은 사용자의 컴퓨터 내부(`%APPDATA%` 또는 `Application Support`)에만 암호화/보관되며, 외부 클라우드 서버로 절대 전송되지 않습니다.
- **음성/영상 비저장 원칙**: 마이크와 카메라는 연습 중에만 실시간으로 화면과 스크롤을 돕기 위해 동작할 뿐, 음성 파일이나 영상 파일로 디스크에 녹음·녹화되지 않습니다.

## 2. 빠른 시작 (Quick Start)

처음 사용하시는 경우 [5분 빠른 시작 가이드(QUICK_START_KO.md)](QUICK_START_KO.md)를 참고하시면 손쉽게 첫 연습을 마칠 수 있습니다.

1. **대본 작성**: 왼쪽 `[+ 새 대본 작성]` 버튼을 누르고 제목과 내용을 입력합니다.
2. **프롬프터 진입**: 화면 우측 상단의 `[프롬프터 시작]` 버튼을 누릅니다.
3. **연습 제어**: `스페이스바(Space)`를 눌러 3초 카운트다운 후 스크롤을 시작하고, 일시정지 및 재개를 조절합니다.

## 3. 대본(스크립트) 관리 기능

![대본 편집 및 서식 도구](images/guide-script-editor.png)

- **새 대본 생성 & 자동 저장**: 입력을 시작하면 실시간으로 변경 사항이 자동 저장됩니다.
- **대본 복제**: 기존 대본을 기반으로 다른 회사용 변형 대본을 만들고 싶을 때 사이드바의 `[대본 복제]` 기능을 사용합니다.
- **검색 및 태그**: 상단 검색창에서 제목이나 본문 키워드를 입력해 원하는 대본을 1초 만에 찾을 수 있으며, 면접 단계별 태그(`1차면접`, `임원면접`, `기술발표`)로 분류할 수 있습니다.
- **즐겨찾기 (별표)**: 자주 연습하는 핵심 대본은 별표 아이콘을 눌러 목록 상단에 고정합니다.
- **삭제 및 복구**: 실수로 삭제한 대본은 휴지통 목록에서 언제든 복구할 수 있습니다.
- **텍스트/마크다운 내보내기**: 작성된 대본을 `TXT` 파일이나 `Markdown(.md)` 파일로 내보내 외부 편집기나 모바일에서 확인할 수 있습니다.

## 4. 텔레프롬프터 상세 사용법

![텔레프롬프터 컨트롤 패널](images/guide-prompter-controls.png)

- **수동 스크롤**: 마우스 휠을 굴리거나 키보드 `위/아래 방향키`로 원하는 위치로 자유롭게 이동합니다.
- **자동 스크롤**: 지정한 속도(WPM)에 맞춰 글자가 위로 일정하게 흘러갑니다.
- **말하기 속도 (WPM 조절)**:
  - 분당 단어 수(Words Per Minute)를 60부터 300까지 조절할 수 있습니다.
  - 보통 한국어 발표 기준 **120~140 WPM**이 청중이 듣기에 가장 편안하고 차분한 속도입니다.
- **문장/문단 건너뛰기**: 연습 중 말이 꼬였을 때 키보드 `J(이전 문장)` / `K(다음 문장)`를 눌러 즉시 이동할 수 있습니다.
- **진행률 및 남은 시간**: 화면 상단에 전체 대본 대비 진행률(%)과 현재 속도 기준 남은 읽기 시간이 초 단위로 실시간 계산되어 페이스 조절을 돕습니다.
- **항상 위 (Always on Top)**: 화상 회의 창이나 카메라 프로그램 위에 프롬프터를 띄워두고 연습할 수 있도록 창 고정 기능을 제공합니다.
- **다중 모니터 & 전체 화면**: 모니터가 여러 대인 경우 카메라가 부착된 모니터로 창을 끌어다 놓고 `F11(전체 화면)`을 켜면 방해 요소 없는 집중 환경이 조성됩니다.

## 5. 효과적인 모의 면접 및 발표 연습 방법

### ① 문장 전체를 다 읽지 말고 키워드 중심으로!
대본에 적힌 글자 하나하나를 그대로 읽으려 하면 눈동자가 좌우로 움직여 '글을 읽고 있다'는 느낌을 줍니다.  
대본 작성 시 핵심 키워드(예: `[동기] 고객 피드백 개선 -> [행동] 데이터 30% 증가`) 위주로 짧게 구성하여, 키워드를 눈으로 훑고 자연스러운 말로 풀어내는 연습을 하세요.

### ② STAR 기법으로 답변 구성하기
경험 질문에 답할 때는 다음 4단계 구조를 프롬프터에 문단으로 구분해 두고 연습해 보세요:
- **S (Situation)**: 당시 어떤 상황이었는가?
- **T (Task)**: 내가 해결해야 할 과제나 문제는 무엇이었는가?
- **A (Action)**: 내가 실제로 취한 구체적 조치는 무엇인가?
- **R (Result)**: 그 결과 어떤 성과나 배움을 얻었는가?

### ③ 카메라 위치와 시선 맞추기
텔레프롬프터 창을 웹캠 렌즈 바로 아래 중앙에 배치하고, 가이드 라인을 렌즈 높이에 맞추면 카메라를 똑바로 응시하는 정면 시선이 완벽하게 유지됩니다.

### ④ 최종 단계는 대본 없이 연습하기
처음에는 자동 스크롤을 보며 연습하고, 익숙해지면 스크롤을 멈춘 뒤 키워드만 슬쩍 보며 말하는 단계로 넘어가세요. 마지막에는 프롬프터 없이도 유창하게 말할 수 있게 됩니다.

## 6. 음성 인식 자동 스크롤 안내

![음성 인식 스크롤 설정](images/guide-speech-recognition.png)

마이크 아이콘을 켜면 내가 입으로 말하는 문장을 컴퓨터가 실시간으로 인식하여 읽고 있는 위치로 대본을 부드럽게 스크롤합니다.

- **지원 언어**: 한국어(`ko-KR`), 영어(`en-US`) 등 주요 언어 선택 지원
- **마이크 권한**: 최초 실행 시 시스템 마이크 사용을 허용해야 합니다.
- **인식률이 떨어질 때의 원인과 대처**:
  - **주변 소음**: 조용한 환경에서 연습하거나 마이크를 입에 더 가깝게 두세요.
  - **전문 용어/외래어**: 영어 기술 용어나 약어가 대본에 있을 경우 음성 인식기가 다르게 받아들일 수 있습니다. 이럴 때는 키보드 방향키로 언제든 수동 조작이 가능합니다.
  - **웅얼거림**: 발음을 또박또박 발성하면 음성 인식 정확도와 실제 면접 전달력이 동시에 향상됩니다.
- **네트워크 및 프라이버시**: 음성 데이터는 화면 스크롤 좌표를 계산하기 위한 목적으로만 처리되며, 오디오 파일로 저장되거나 외부에 보관되지 않습니다.

## 7. 카메라 미리보기 기능

![카메라 미리보기 연습 화면](images/guide-camera-preview.png)

- 프롬프터 배경에 내 얼굴이 비치는 **실시간 카메라 미리보기**를 켤 수 있습니다.
- 발표 중 무의식적으로 짓는 표정, 고개 기울임, 불안한 시선 처리를 직접 보면서 모니터링할 수 있습니다.
- **카메라가 없는 PC**: 웹캠이 없어도 텔레프롬프터 대본 스크롤 기능은 100% 정상 작동합니다.
- **영상 비저장**: 카메라는 화면에 거울처럼 비춰줄 뿐, 어떤 영상 파일도 컴퓨터에 녹화·저장되지 않습니다.

## 8. 환경 설정 및 단축키 안내

![환경 설정 화면](images/guide-settings-modal.png)

### 설정 옵션
- **테마**: 다크 모드(눈의 피로 감소), 라이트 모드 지원
- **텍스트 스타일**: 글자 크기(20px~64px), 줄 간격(1.2~2.5) 조절
- **기본값 설정**: 대본 생성 시 적용할 기본 WPM 및 기본 인식 언어 설정

### 키보드 단축키 일람표
| 단축키 | 기능 설명 |
| :--- | :--- |
| **`Space`** | 스크롤 재생 / 일시정지 |
| **`↑ / ↓`** | 한 줄 단위 수동 스크롤 |
| **`J / K`** | 이전 문장 / 다음 문장으로 건너뛰기 |
| **`R`** | 대본 처음 위치로 되돌리기 (리셋) |
| **`+ / -`** | 스크롤 속도(WPM) 빠르게 / 느리게 |
| **`F11`** | 전체 화면 모드 켜기 / 끄기 |
| **`ESC`** | 프롬프터 종료 및 편집창 복귀 |

## 9. 데이터 백업 및 복원

![대본 백업 및 복원 화면](images/guide-backup-restore.png)

- **JSON 백업 파일 만들기**: 설정 메뉴에서 `[대본 전체 내보내기(JSON)]`를 클릭하여 원하는 안전한 폴더(USB, 외장하드, 클라우드 드라이브 등)에 저장합니다.
- **새 컴퓨터로 대본 옮기기**: 새 컴퓨터에 RehearsePrompt를 설치한 후 `[대본 복원하기(JSON)]`를 누르고 백업 파일을 선택하면 작성했던 모든 대본과 태그가 완벽하게 복원됩니다.
- **주의사항**: 복원 시 기존 대본을 덮어쓸지 여부를 묻는 확인창이 뜨므로 중요한 대본이 있는 경우 미리 백업해 두세요.

## 10. 화면 공유 관련 투명성 고지

RehearsePrompt는 사용자의 진정한 발표 실력 향상을 위해 제작된 소프트웨어입니다.

> **📢 화면 공유 시 주의사항**  
> - 본 프로그램은 Zoom, Google Meet, Microsoft Teams 등 화상 회의 플랫폼에서 **자신의 창을 몰래 숨기는 기능(Stealth Overlay)을 제공하지 않습니다.**  
> - 화상 회의에서 **"전체 화면 공유(Entire Screen)"**를 선택할 경우, 텔레프롬프터 창이 상대방 화면에도 그대로 보이게 됩니다.  
> - 특정 프레젠테이션 창(예: PowerPoint, 브라우저)만 선택하여 공유하는 "창 공유(Window Share)"를 사용할 때도, 시험이나 면접 규정에 위배되지 않는지 사전에 반드시 확인하십시오.  
> - 면접 및 공식 평가에서는 반드시 주최 측의 가이드라인을 준수하십시오.

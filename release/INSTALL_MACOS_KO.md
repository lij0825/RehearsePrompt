# RehearsePrompt macOS 설치 가이드

이 문서는 macOS 환경에서 **RehearsePrompt**를 안전하고 올바르게 설치, 권한 설정, 실행 차단 대처 및 제거할 수 있도록 단계별로 안내합니다.

---

## 지원 환경

- **지원 macOS 버전**: macOS 11.0 (Big Sur) 이상 (macOS 12 Monterey, macOS 13 Ventura, macOS 14 Sonoma, macOS 15 Sequoia 지원)
- **Apple Silicon 지원 여부**: **완벽 지원** (M1, M2, M3, M4 프로세서 전용 `arm64` 아키텍처 네이티브 바이너리 제공)
- **Intel 지원 여부**: **완벽 지원** (Intel Core i5, i7, i9 프로세서 전용 `x64` 아키텍처 네이티브 바이너리 제공)
- **Universal 여부**: 최적의 다운로드 용량(85MB 수준)과 실행 속도를 위해 **Apple Silicon용과 Intel용 개별 DMG로 분리 배포**됩니다.  
  *(내 Mac의 칩셋 종류는 화면 좌측 상단 사과 메뉴  > [이 Mac에 관하여]에서 확인할 수 있습니다.)*
- **필요한 저장 공간**: 최소 **300 MB 이상의 여유 디스크 공간**  
  - 다운로드 DMG 디스크 이미지: 약 85 MB
  - 애플리케이션 번들(.app): 약 250 MB
  - 대본 데이터 저장 공간: 약 수 MB
- **마이크 권한**: **음성 기반 자동 스크롤 사용 시 필요** (발화 문장 실시간 추적용)
- **카메라 권한**: **실시간 카메라 미리보기 사용 시 필요** (시선 및 표정 교정용 거울 모드)

---

## 설치 파일 종류

| 파일 | 설명 |
|---|---|
| **.dmg** | 일반적인 macOS 설치용 디스크 이미지 (`RehearsePrompt-1.0.0-macOS-arm64.dmg` 또는 `x64.dmg`) |
| **.app** | 애플리케이션 번들 (`RehearsePrompt.app`, 시스템에서 독립 실행 가능한 표준 앱 패키지) |
| **.tar.gz** | 자동 업데이트나 고급 배포용일 수 있음 (CLI 배포 또는 백업 아카이브용 압축 파일) |

## 설치 절차

### 1. DMG 파일 열기
다운로드한 `.dmg` 파일(예: `RehearsePrompt-1.0.0-macOS-arm64.dmg`)을 더블 클릭하여 디스크 이미지를 마운트합니다.

![macOS DMG 열기 화면](images/macos-dmg-mount.png)

### 2. 앱 아이콘을 Applications 폴더로 드래그
열린 창에서 **RehearsePrompt 아이콘**을 오른쪽의 **Applications (응용 프로그램) 폴더** 바로가기로 끌어다 놓습니다.

![macOS Applications 드래그 앤 드롭 화면](images/macos-dmg-drag-and-drop.png)

### 3. DMG 꺼내기
복사가 완료되면 창을 닫고, Finder 사이드바의 추출 아이콘(⏏)을 클릭하거나 바탕화면의 마운트 디스크를 휴지통으로 끌어 **디스크 이미지를 꺼냅니다(Unmount)**.

### 4. Applications에서 앱 실행
**Finder > [응용 프로그램]** 폴더 또는 **Launchpad**에서 **RehearsePrompt**를 찾아 클릭하여 실행합니다.

### 5. 첫 실행 권한 확인
앱이 실행되면 시스템에서 인터넷 다운로드 앱 실행 여부를 묻는 보안 확인창이 나타납니다. 확인 후 실행합니다.

### 6. 마이크 권한 선택
프롬프터 화면에서 마이크 기능을 처음 활성화할 때 **"RehearsePrompt에서 마이크에 접근하려고 합니다"** 알림창이 뜹니다. 음성 추적 스크롤을 위해 **`[허용]`**을 선택합니다.

![macOS 마이크 권한 허용 화면](images/macos-microphone-prompt.png)

### 7. 카메라 권한 선택
카메라 미리보기(거울 모드)를 켤 때 **"RehearsePrompt에서 카메라에 접근하려고 합니다"** 알림창이 뜹니다. 표정 모니터링을 원하실 경우 **`[허용]`**을 선택합니다.  
*(카메라 권한을 거부하더라도 대본 작성 및 스크롤 기능은 100% 정상 동작합니다.)*

### 8. 온보딩 완료
기본으로 준비된 모의 면접 예시 대본이 화면에 표시되면 설치 및 첫 설정이 완료됩니다.

## 앱 실행이 차단될 때

macOS의 보안 정책(Gatekeeper)에 따라 실행 방식이 다를 수 있으므로, **서명·공증된 배포판**과 **개발용 미서명 빌드**를 명확히 구분하여 대응해야 합니다.

### 공증된 배포판
- **Gatekeeper 검증**: Apple Notary Service의 정식 공증 티켓(Stapled Ticket)이 포함되어 있습니다.
- **일반적인 실행 절차**: 더블 클릭 시 Apple의 보안 검사를 자동으로 통과하며, 최초 1회 "인터넷에서 다운로드된 앱" 확인 팝업에서 `[열기]`를 클릭하면 즉시 정상 실행됩니다.

### 미서명 개발 빌드
비영리 오픈소스 개발 빌드나 자체 컴파일 빌드는 Apple Developer 유료 인증서가 서명되어 있지 않아 **"확인되지 않은 개발자"** 경고와 함께 실행이 차단될 수 있습니다.

![macOS Gatekeeper 경고 화면](images/macos-gatekeeper-warning.png)

> **⚠️ 보안 주의사항**  
> 시스템 보안 기능을 무조건 끄거나 출처를 알 수 없는 파일을 강제로 실행하는 것은 권장되지 않습니다.  
> 반드시 다음 안전 점검 절차를 확인하십시오:

- **공식 배포 경로인지 확인**:  
  다운로드한 사이트가 공식 RehearsePrompt GitHub 저장소인지 확인하십시오.
- **파일 해시 확인**:  
  터미널에서 `shasum -a 256 <파일명.dmg>` 명령을 실행하여 공식 릴리스 공지에 명시된 SHA-256 체크섬과 일치하는지 확인하십시오.
- **개발 빌드인지 확인**:  
  현재 파일이 공증되지 않은 개발/테스트 목적의 릴리스인지 배포 릴리스 노트를 확인하십시오.
- **조직 보안 정책을 먼저 확인해야 함**:  
  회사, 학교, 연구소 등의 업무용 Mac인 경우 임의 실행을 자제하고 조직의 IT 보안 담당 부서에 문의하십시오.
- **무조건 보안 기능을 끄도록 안내하지 않음**:  
  터미널에서 Gatekeeper 전체를 무력화하는 명령어(`spctl --master-disable` 등)를 실행하지 마십시오. 신뢰할 수 있는 개발 빌드에 한해 macOS의 공식 예외 절차인 **[시스템 설정] > [개인정보 보호 및 보안] > [보안] > "확인 없이 열기"** 버튼을 통해서만 안전하게 승인하십시오.

## 권한 변경

설치 후 언제든 macOS **[시스템 설정] > [개인정보 보호 및 보안]** 메뉴에서 RehearsePrompt의 권한을 확인하고 변경할 수 있습니다.

![macOS 개인정보 보호 및 보안 설정 화면](images/macos-security-privacy-settings.png)

- **마이크**:  
  - **필요 기능**: 프롬프터의 **'음성 인식 기반 스마트 스크롤'**에 사용됩니다.
  - **설명**: 사용자가 읽는 현재 문장을 실시간으로 매칭하여 화면을 내리는 데 사용되며, 오디오 파일로 녹음되거나 저장되지 않습니다.
- **카메라**:  
  - **필요 기능**: **'실시간 표정/시선 모니터링 미리보기'**에 사용됩니다.
  - **설명**: 배경 화면에 거울처럼 웹캠을 띄워 시선 이탈을 방지하며, 영상으로 저장되지 않습니다. 권한을 끄더라도 대본 읽기 기능은 정상 작동합니다.
- **접근성 (Accessibility)**:  
  - **필요 기능**: 전체 화면 모드 및 다른 창 위에 프롬프터를 띄워두는 **'항상 위(Always on Top)'** 동작 시 전역 단축키 수신에 사용될 수 있습니다.
- **파일 및 폴더**:  
  - **필요 기능**: 작성한 대본을 텍스트 파일(`TXT`)이나 마크다운(`MD`)으로 내보내거나, **JSON 백업 파일을 원하는 폴더에 저장하고 복원**할 때 접근 권한이 필요합니다.

## 제거 방법

앱을 시스템에서 완전히 제거하고자 할 경우 다음 4단계를 따르십시오:

### 1. 앱 종료
RehearsePrompt가 실행 중이라면 키보드의 **`Command + Q`**를 누르거나 상단 메뉴 모음에서 `[RehearsePrompt 종료]`를 선택하여 완전히 끕니다.

### 2. Applications에서 앱 삭제
Finder를 열고 **[응용 프로그램]** 폴더로 이동한 뒤, **`RehearsePrompt.app`**을 마우스로 끌어 **휴지통**에 넣고 휴지통을 비웁니다.

### 3. 필요하면 앱 데이터 폴더 삭제
프로그램을 지워도 사용자가 작성한 대본 파일은 실수로 인한 삭제를 방지하기 위해 남아 있습니다. 대본 데이터까지 완전히 삭제하고 싶다면 Finder 메뉴의 **[이동] > [폴더로 이동...]**을 누르고 다음 경로를 입력하여 해당 폴더를 삭제하십시오:  
`~/Library/Application Support/rehearse-prompt`

### 4. 삭제 전 대본과 JSON 백업 확인
데이터 폴더를 삭제하면 저장된 모든 대본과 세션 기록이 영구히 사라집니다. 중요한 연습 대본이 있는 경우, **반드시 삭제 전에 앱 설정 메뉴의 `[대본 전체 내보내기(JSON)]`를 통해 안전한 외장 드라이브나 클라우드에 백업했는지 확인**하십시오.

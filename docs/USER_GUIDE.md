# RehearsePrompt 사용자 사용 가이드 (User Guide)

RehearsePrompt는 면접관을 당당하게 응시하면서 자연스럽게 답변을 연습할 수 있도록 돕는 **모의 면접 및 발표 연습용 데스크톱 텔레프롬프터**입니다.

> [!IMPORTANT]
> **정직하고 투명한 연습을 위한 윤리적 원칙**:
> RehearsePrompt는 자신의 스피치 역량을 훈련하고 개선하기 위한 도구입니다. 실제 온라인 면접이나 시험 감독 시스템을 속이거나 화면 공유에서 앱을 몰래 숨기는 비인가 기능은 일절 포함되어 있지 않으며, 공식 화상 회의(Zoom, Meet, Teams)에서도 일반 데스크톱 창으로 정상 노출됩니다.

---

## 1. 주요 화면 구성

RehearsePrompt는 크게 **대본 편집기(Editor Mode)**와 **텔레프롬프터(Prompter Mode)** 두 가지 화면으로 구성되어 있습니다.

```text
┌─────────────────────────┬─────────────────────────────────────────────────┐
│ [대본 목록]             │ [대본 편집기 / 텔레프롬프터 연습창]             │
│ - 새 대본 작성 (+)      │                                                 │
│ - 검색 및 즐겨찾기 필터 │ 제목: 2026 하반기 신입 프론트엔드 모의 면접     │
│ - 대본 리스트           │ 본문 작성 및 글자 수 / 예상 스피치 시간 확인     │
│ - 휴지통 / 복구         │                                                 │
│ - JSON/TXT 가져오기     │ [프롬프터 시작 버튼] ─────────▶ [프롬프터 모드] │
└─────────────────────────┴─────────────────────────────────────────────────┘
```

---

## 2. 대본 관리하기 (Script Management)

### 2.1 새 대본 작성 및 자동 저장 (Auto-Save)
1. 좌측 사이드바 상단의 **[+ 새 대본]** 버튼을 누릅니다.
2. 상단에 대본 제목을 입력하고, 아래 본문 영역에 답변이나 발표 대본을 작성합니다.
3. 입력 중인 내용은 **1초(1,000ms)마다 로컬 DB에 자동 저장**되므로 앱이 갑자기 닫히더라도 작성 내용이 유실되지 않습니다.

### 2.2 예상 소요 시간 및 통계 확인
- 본문 입력 영역 하단에 **총 글자 수, 단어 수, 공백 제외 글자 수**가 실시간으로 표시됩니다.
- 사용자가 설정한 발화 속도(예: 180 WPM)를 기준으로 **예상 발표 시간(분:초)**이 자동 산출됩니다.

### 2.3 즐겨찾기, 복제, 삭제 및 복구
- **즐겨찾기 (Star)**: 자주 연습하는 핵심 질문 대본에 별표를 클릭하여 상단에 고정합니다.
- **대본 복제 (Duplicate)**: 기존 대본을 기반으로 다른 버전의 답변을 작성하고 싶을 때 복제 기능을 사용합니다.
- **삭제 및 휴지통 복구**: 삭제한 대본은 즉시 영구 삭제되지 않고 '휴지통'으로 이동하며, 언제든지 [복구] 버튼을 눌러 되살릴 수 있습니다.

### 2.4 가져오기 및 내보내기 (Import & Export)
- **내보내기 (Export)**: 작성한 대본을 `.json`(버전 이력 및 설정 포함) 또는 `.txt`(순수 텍스트) 파일로 로컬 PC에 저장합니다.
- **가져오기 (Import)**: 다른 PC에서 내보낸 JSON 대본 파일이나 텍스트 문서를 불러와 목록에 추가합니다. 형식 검증을 통해 손상된 파일은 안전하게 차단됩니다.

## 3. 텔레프롬프터 모드 사용법 (Prompter Mode)

대본 작성을 마치고 우측 상단의 **[프롬프터 시작]** 버튼을 클릭하면 발표 연습 전용 뷰가 열립니다.

### 3.1 두 가지 스크롤 방식

| 모드 | 작동 원리 | 추천 상황 |
| :--- | :--- | :--- |
| **속도 기반 자동 스크롤 (WPM Mode)** | 일정한 속도(WPM)로 대본이 위로 부드럽게 스크롤됩니다. | 정해진 발표 시간(예: 3분 스피치)에 맞추어 일정한 템포를 유지하는 훈련 |
| **음성 인식 연동 스크롤 (Speech Mode)** | 마이크로 입력되는 사용자의 목소리를 실시간 분석하여 읽고 있는 문장을 자동 추적합니다. | 면접관의 질문에 생각하며 유연하게 답변하거나 멈춤(Pause)이 많은 모의 면접 |

### 3.2 음성 인식 스크롤 상세 활용법
1. 프롬프터 상단에서 **[음성 인식 스크롤]** 탭을 활성화합니다.
2. **[마이크 시작]** 버튼을 누르면 마이크 레벨 메터(초록색 바)가 음성 크기에 맞춰 반응합니다.
3. 말을 시작하면 인식 엔진이 현재 읽고 있는 문장을 찾아 **파란색 하이라이트**로 강조하고 시선 유도선 위치로 자동 스크롤합니다.
4. **수동 위치 보정 (오인식 대응)**: 만약 발음을 잘못 인식하여 엉뚱한 위치로 이동했거나 이전 문장을 다시 읽고 싶다면, **원하는 문장을 마우스로 직접 클릭**하세요. 즉시 해당 문장으로 기준 위치가 보정됩니다.

### 3.3 시선 처리 가이드라인 (Eye-Contact Guide Line)
- 프롬프터 화면 상단에는 카메라 렌즈 바로 아래에 위치하는 **시선 유도 기준선(파란색 가이드 라인)**이 표시됩니다.
- 모니터의 웹캠 렌즈 바로 아래에 프롬프터 창을 배치하고 이 유도선을 바라보며 문장을 읽으면, 화면을 보는 티가 나지 않고 면접관과 자연스럽게 눈을 마주치는(Eye Contact) 인상을 줄 수 있습니다.

## 4. UI 커스터마이징 및 환경설정

- **글자 크기 (Font Size)**: 20px ~ 48px까지 슬라이더로 조절하여 모니터 거리와 시력에 맞게 조정합니다.
- **줄 간격 및 여백**: 시선 분산을 막기 위해 중앙 정렬 여백(Narrow / Normal / Wide)을 선택할 수 있습니다.
- **창 반투명도 (Opacity)**: 배경 투명도를 40% ~ 100%까지 조절하여 뒤에 화상 회의 화면이나 타이머를 띄워두고 함께 볼 수 있습니다.
- **반전/미러 모드 (Mirroring)**: 빔프로젝터나 하프미러 하드웨어 프롬프터를 사용할 경우 좌우 반전 기능을 켭니다.

---

## 5. 키보드 단축키 안내 (Keyboard Shortcuts)

프롬프터 모드에서는 마우스 없이 키보드만으로 빠르게 제어할 수 있습니다.

| 단축키 | 기능 |
| :--- | :--- |
| `Space` | 스크롤 시작 / 일시 정지 (Play / Pause) |
| `Esc` | 프롬프터 종료 및 대본 편집 화면 복귀 |
| `↑` / `↓` | 스크롤 위치 수동 위/아래 미세 조정 |
| `←` / `→` | 스크롤 속도 감속 / 가속 (WPM 조정) |
| `M` | 마이크 음성 인식 켜기 / 끄기 토글 |
| `F11` (macOS: `Cmd + Ctrl + F`) | 전체 화면 (Fullscreen) 토글 |
| `Home` | 대본 처음으로 즉시 되돌리기 |

> 문서 버전: 1.0.0  
> 최종 수정일: 2026-09-10  
> 상태: 초기 설계 승인 대기

---

## 1. 테스트 전략 개요

RehearsePrompt는 사용자의 실제 면접 및 발표 현장 리허설의 신뢰성을 보장하기 위해 **단위 테스트(Unit Tests), 통합 테스트(Integration Tests), UI/접근성 테스트, 권한/오류 방어 테스트, 성능 벤치마크**의 5단계 검증 파이프라인을 운영합니다.

- **테스트 툴체인**: Vitest (빠른 TypeScript 실행 속도 및 ESM 네이티브 지원), React Testing Library.
- **테스트 작성 원칙**: Given-When-Then 패턴 준수, `@DisplayName` / `describe-it`에 명확한 한국어 시나리오 및 기대 결과 서술.
- **자동화 실행 커맨드**: `npm test` 또는 `npm run test:run`.

## 2. 자동화 테스트 범위 명세

### 2.1 단위 테스트 (Unit Tests)
- **WPM 및 예상 시간 계산기 (`calculateReadingTime`)**:
  - 한국어 어절 기준(분당 130~150단어) 및 영문 단어 기준 정확도 검증.
  - 빈 문자열, 특수문자만 있는 문자열, 개행만 있는 문자열 방어.
- **텍스트 파서 (`splitSentences`, `splitParagraphs`)**:
  - 한국어 종결 어미(습니다, 요, 다 등) 및 구두점(. ! ? \n) 정밀 분리.
  - 마침표가 포함된 약어(e.g., etc., Dr.) 및 숫자 소수점(3.14) 오분리 방지.
- **스크롤 보간 알고리즘 (`interpolateScroll`)**:
  - 속도 변경 시 서브픽셀 댐핑 스무딩 함수 수학적 수렴 검증.
- **음성 인식 유사도 매칭 (`findMatchingSentenceIndex`)**:
  - Levenshtein 거리 및 어절 n-gram 일치 점수 산출 정밀도 검증.
- **JSON 백업 검증기 (`validateBackupJson`)**:
  - 필수 필드 누락, ID 형식 위반, 악의적인 스크립트 태그 포함 시 검증 및 정제.

### 2.2 통합 테스트 (Integration Tests)
- **스크립트 생명주기**: 생성 -> 입력 디바운스 자동 저장 -> 저장 상태 UI 반영 -> 앱 재시작 모의 복원.
- **버전 스냅샷 관리**: 10회 이상 수정 시 최대 10개 버전 스냅샷 유지 및 FIFO 회전 검증.
- **연습 세션 기록**: 프롬프터 모드 시작 -> 일시정지 -> 재개 -> 완독 -> 세션 통계 저장 및 조회.
- **단축키 충돌 검사**: 유효한 단축키 포맷 검증 및 잘못된 키 조합 등록 방어.

### 2.3 권한 및 에러 방어 테스트
- **마이크 권한 거부**: 브라우저 권한 API가 거부 상태일 때 앱 크래시 없이 일정 속도 모드로 폴백하는지 검증.
- **카메라 권한 거부**: 카메라 접근 실패 시 프리뷰 영역이 안내 플레이스홀더로 정상 대체되는지 검증.
- **디스크 쓰기 권한 부족/경로 에러**: 파일 저장 실패 시 데이터 유실 없이 친절한 에러 다이얼로그 노출 확인.

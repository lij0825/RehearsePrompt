# RehearsePrompt 권한, 개인정보 보호 및 윤리 강령 정책

본 문서는 RehearsePrompt의 데이터 처리 방식, 마이크 및 시스템 권한 사용 목적, 외부 서버 전송 여부, 그리고 공정한 면접 문화를 위한 윤리적 개발 원칙을 투명하게 공개합니다.

---

## 1. 100% 로컬 데이터 처리 원칙 (Zero Cloud Storage)

RehearsePrompt는 사용자의 대본과 개인적인 면접 준비 내용이 가장 민감한 개인정보라는 사실을 엄격히 인지하고 있습니다.

- **외부 서버 무전송**: 본 애플리케이션에는 사용자 대본을 수집하거나 원격 클라우드로 동기화하는 백엔드 서버가 일절 존재하지 않습니다.
- **원격 분석 도구 부재**: Google Analytics, Sentry, Mixpanel 등 사용자의 행동이나 키 입력을 추적하는 서드파티 텔레메트리(Telemetry) SDK가 전혀 포함되어 있지 않습니다.
- **로컬 파일 시스템 보관**: 모든 데이터(대본 내용, 편집 히스토리, 연습 세션 타임스탬프, 사용자 환경설정)는 오직 사용자의 컴퓨터 로컬 드라이브의 앱 데이터 영역에만 안전하게 저장됩니다:
  - **Windows**: `%APPDATA%\RehearsePrompt\storage\`
  - **macOS**: `~/Library/Application Support/RehearsePrompt/storage/`

---

## 2. 오디오 입력 처리 및 녹음 데이터 미저장 (Zero Audio Logging)

음성 인식 기반 텔레프롬프터 자동 스크롤 기능을 구동하기 위해 시스템 마이크 권한을 요청합니다.

- **마이크 권한 사용 목적**: 오직 사용자의 발화 음량을 측정(초록색 볼륨 레벨 메터)하고, 사용자가 읽고 있는 문장의 위치를 추적(Web Speech API)하기 위한 용도로만 사용됩니다.
- **원본 음성 미저장 원칙**:
  - 마이크를 통해 유입되는 원본 오디오 스트림(PCM, WAV, MP3 등)은 메모리 상에서 실시간 분석된 직후 즉각 파기됩니다.
  - 디스크에 음성 녹음 파일이 생성되거나 로그 파일에 오디오 덤프가 기록되는 일은 결코 발생하지 않습니다.
- **음성 인식 처리 엔진**:
  - 시스템 브라우저 엔진의 Web Speech API를 활용합니다.
  - 최신 OS 및 브라우저 정책에 따라 일부 음성 모델 참조 시 로컬 오프라인 엔진 또는 운영체제 기본 음성 서비스가 호출될 수 있으며, 앱 자체는 음성 데이터를 보관하지 않습니다.

---

## 3. 공정성과 투명성을 위한 윤리적 목적 제한 (Ethical Boundaries)

RehearsePrompt는 취업 준비생과 발표자가 **사전에 충실히 역량을 갈고닦을 수 있도록 돕는 자율 훈련 도구**입니다. 시험이나 실제 면접 평가 시스템을 기만하는 용도로 변질되는 것을 엄격히 방지하기 위해 다음 기능은 의도적으로 구현하지 않았으며, 향후에도 지원하지 않습니다.

### 3.1 화면 공유 및 캡처 감시 우회 금지
- Windows의 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` 또는 macOS의 `NSWindow.sharingType = .none`과 같이 화면 공유 시 텔레프롬프터를 몰래 숨기는 화면 캡처 회피 API를 절대 사용하지 않습니다.
- Zoom, Google Meet, Microsoft Teams, Discord 등에서 전체 화면 또는 앱 창을 공유할 경우 RehearsePrompt 화면은 일반적인 윈도우 창과 동일하게 투명하게 노출됩니다.

### 3.2 온라인 시험 감독 및 안티치트 감지 우회 금지
- 온라인 자격증 시험, 대기업 온라인 인적성 및 코딩 테스트 등에서 가동되는 프로세스 감시(Anti-cheat), 화면 모니터링, 포커스 감지(Window Blur Detection)를 무력화하는 해킹/인젝션 기술을 일절 포함하지 않습니다.
- RehearsePrompt는 정상적인 데스크톱 프로세스로 등록되어 OS 프로세스 목록에 투명하게 표시됩니다.

## 4. 데이터 영구 파기 및 초기화 (Data Wipe)

사용자가 원할 경우 언제든지 앱 내에 저장된 모든 흔적을 완전히 삭제할 수 있습니다.

1. RehearsePrompt 앱을 완전히 종료합니다.
2. 아래의 로컬 데이터 디렉터리를 탐색기 또는 터미널에서 영구 삭제합니다:
   - **Windows**: `rmdir /s /q "%APPDATA%\RehearsePrompt"`
   - **macOS**: `rm -rf "~/Library/Application Support/RehearsePrompt"`
3. 폴더 삭제 즉시 모든 대본, 리비전, 설정이 복구 불가능하게 영구 파기됩니다.

# RehearsePrompt macOS 설치 가이드 (일반 사용자용)

이 문서는 Mac을 처음 사용하는 분도 **RehearsePrompt**를 쉽고 안전하게 설치하고 마이크 권한을 설정할 수 있도록 단계별로 안내합니다.

---

## 1. 내 Mac에 맞는 설치 파일 확인 및 다운로드

Mac의 프로세서(CPU) 종류에 따라 알맞은 파일을 선택해야 최고의 성능과 배터리 효율을 얻을 수 있습니다.

### 내 Mac의 프로세서 확인 방법
1. Mac 화면 맨 왼쪽 위의 **사과 아이콘()**을 클릭합니다.
2. **[이 Mac에 관하여]**를 클릭합니다.
3. 창에 표시된 정보를 확인합니다:
   - **"칩: Apple M1 / M2 / M3 / M4"**로 표시됨 👉 **Apple Silicon 버전** 다운로드
   - **"프로세서: Intel Core i5 / i7"** 등으로 표시됨 👉 **Intel 버전** 다운로드

| 파일 이름 | 대상 기기 | 설명 |
| :--- | :--- | :--- |
| **`RehearsePrompt-1.0.0-macOS-arm64.dmg`** | **M1 / M2 / M3 / M4 Mac (최신 Mac 전용)** | Apple Silicon 칩에 최적화된 고성능 저전력 빌드 |
| **`RehearsePrompt-1.0.0-macOS-x64.dmg`** | **Intel 기반 구형 Mac 전용** | 2020년 이전 출시된 Intel Mac 전용 빌드 |

---

## 2. 단계별 설치 방법

### 1단계: DMG 파일 열기
다운로드한 `.dmg` 파일을 더블 클릭하여 엽니다.

### 2단계: 응용 프로그램(Applications) 폴더로 드래그
열린 창에서 **RehearsePrompt 아이콘**을 마우스로 잡고 오른쪽의 **Applications (응용 프로그램) 폴더** 위로 끌어다 놓습니다.

![macOS DMG 드래그 앤 드롭 설치 화면](images/macos-dmg-drag-and-drop.png)

복사가 끝나면 DMG 창을 닫고, 바탕화면에 생성된 디스크 아이콘을 우클릭하여 **`[추출]`**합니다.

---

## 3. "확인되지 않은 개발자" 안내창 대처 방법

응용 프로그램 폴더에서 RehearsePrompt를 처음 실행할 때 **"Apple에서 악성 소프트웨어가 있는지 확인할 수 없기 때문에 열 수 없습니다"**라는 안내창이 나타날 수 있습니다.

![macOS Gatekeeper 열기 확인 화면](images/macos-gatekeeper-open.png)

> **⚠️ 왜 이런 메시지가 나타나나요?**  
> Apple은 연회비가 발생하는 유료 Apple Developer 프로그램 계정으로 공증(Notarization)을 받지 않은 비영리 오픈소스 프로그램에 대해 기본적으로 이 보안 안내창을 띄웁니다.  
> **악성코드가 감지되어 뜨는 경고가 아니며, 순수한 연습용 앱이므로 안심하셔도 됩니다.**

### 해결 방법 (안전하게 첫 실행하기)

**[방법 1: Control 키 누르고 열기 (가장 간편)]**
1. **[Finder]**를 열고 **[응용 프로그램]** 폴더로 이동합니다.
2. 키보드의 **`Control`** 키를 누른 채로 **RehearsePrompt** 아이콘을 클릭합니다.
3. 나타나는 메뉴에서 맨 위의 **`[열기]`**를 클릭합니다.
4. 새로운 확인창이 뜨면 **`[열기]`** 버튼을 누릅니다.  
   *(한 번만 열어두면 이후에는 평소처럼 더블 클릭만으로 바로 열립니다!)*

**[방법 2: 시스템 설정에서 허용하기]**
1. 화면 좌측 상단 사과 메뉴() > **[시스템 설정]**으로 들어갑니다.
2. 왼쪽 메뉴에서 **[개인정보 보호 및 보안]**을 클릭합니다.
3. 오른쪽 화면을 아래로 스크롤하여 **[보안]** 섹션을 찾습니다.
4. **"RehearsePrompt의 사용이 차단되었습니다"** 메시지 옆의 **`[확인 없이 열기]`** 버튼을 클릭합니다.

![macOS 시스템 설정 확인 없이 열기 화면](images/macos-security-open-anyway.png)

---

## 4. 마이크 권한 허용하기

대본을 읽을 때 내 음성을 감지하여 화면이 자동으로 스크롤되도록 하려면 마이크 권한이 필요합니다.

![macOS 마이크 권한 요청 팝업 화면](images/macos-microphone-prompt.png)

1. 앱을 처음 실행하고 프롬프터 모드에서 마이크를 켜면 시스템 알림창이 뜹니다.
2. **"RehearsePrompt에서 마이크에 접근하려고 합니다"** 창에서 **`[확인]`**을 클릭합니다.
3. 실수로 거절했을 경우:
   - **[시스템 설정]** > **[개인정보 보호 및 보안]** > **[마이크]**로 이동합니다.
   - 목록에서 **RehearsePrompt**를 찾아 토글 스위치를 **`[켬]`**으로 변경합니다.

---

## 5. 앱 삭제(제거) 방법

앱을 삭제하고 싶을 때는 **[응용 프로그램]** 폴더에서 `RehearsePrompt.app`을 마우스로 끌어 **휴지통**에 넣고 휴지통을 비우시면 완전히 삭제됩니다.

# RehearsePrompt - 알려진 기술적 제한사항 및 가이드 (Known Limitations)

> 문서 버전: 1.0.0  
> 최종 수정일: 2026-09-10  
> 상태: 초기 설계 승인 대기

---

## 1. 음성 인식 및 네트워크 관련 제한사항

### 1.1 Web Speech API 엔진 특성
- RehearsePrompt는 경량화와 설치 편의를 위해 Chromium의 표준 `webkitSpeechRecognition` API를 기본 엔진으로 채택하고 있습니다.
- **네트워크 연결 필요성**: 운영체제 및 Chromium 엔진 정책에 따라 일부 음성 데이터가 임시로 음성 인식 서비스(Google Speech Server 등)를 경유할 수 있습니다.
- **오프라인 환경 제한**: 완전한 인터넷 단절 환경에서는 음성 인식이 제한되거나 작동하지 않을 수 있습니다. 이 경우 앱은 **"일정 속도 자동 스크롤(Constant Speed)"** 또는 **"수동 스크롤"** 모드로 안전하게 폴백할 것을 안내합니다.
- **완전 로컬 음성 인식(Whisper 등)**: whisper.cpp / whisper-rs 등의 로컬 온디바이스 모델은 수백 MB 이상의 신경망 가중치 다운로드와 C++ 컴파일 바이너리 종속성이 요구되므로, MVP 이후 플러그인 확장 아키텍처로 분리되어 있습니다.

### 1.2 주변 소음 및 혼합 언어 발음
- 카페나 소음이 심한 환경, 마이크 입력 볼륨이 너무 작거나 울리는 환경에서는 음성 인식률이 저하될 수 있습니다.
- 한영 혼용 대본(예: "React 컴포넌트의 Lifecycle")의 경우 발음에 따라 외래어가 오인식될 수 있으므로, 어절 편집 거리(Levenshtein) 매칭 임계값을 조정하거나 수동 보정을 병행해야 합니다.

## 2. 화면 공유 및 캡처 관련 윤리적/기술적 제한사항

### 2.1 은닉 기능 일체 미지원 (Anti-Cheat Non-Circumvention)
- 본 앱은 시험 부정행위, 면접관 몰래 대본 읽기, 화면 공유 시 창 숨기기를 지원하지 않습니다.
- 따라서 **OS 화면 전체 공유 시 RehearsePrompt 창은 다른 참여자에게 그대로 노출**됩니다.
- 만약 실제 화상 발표나 모의 면접에서 프롬프터 창을 공유 화면에서 분리하고 싶다면:
  - 회의 소프트웨어(Zoom, Google Meet, Teams 등)의 **"전체 화면 공유" 대신 "특정 애플리케이션 창(예: 파워포인트 슬라이드 쇼 창)만 공유"** 기능을 활용해야 합니다.
  - 앱 내 상단 바 및 온보딩 5단계에서 이 점을 명확히 고지합니다.

## 3. 데이터 저장 및 동기화 제한사항

### 3.1 로컬 파일 시스템 저장 (No Cloud Sync)
- 모든 스크립트와 연습 기록은 사용자 PC 로컬 디스크(`%APPDATA%` 또는 `Application Support`)에 안전하게 저장됩니다.
- 원격 클라우드 자동 동기화 기능은 제공되지 않으므로, 다른 PC로 데이터를 이전하고자 할 때는 설정 화면의 **"JSON 백업 내보내기/가져오기"** 기능을 이용해야 합니다.

### 3.2 버전 히스토리 보관 수
- 스크립트당 최대 10개의 최근 스냅샷만 보관되며, 10개를 초과하면 가장 오래된 스냅샷부터 자동 삭제(FIFO)됩니다.

## 4. 운영체제 및 단축키 제약사항

### 4.1 글로벌 단축키 전역 점유 충돌
- 다른 프로그램(예: Discord, OBS Studio, 특정 게임 클라이언트)이 이미 동일한 단축키를 독점 등록한 경우 등록이 실패할 수 있습니다.
- 이 경우 앱 설정 화면에서 즉시 다른 키 조합(예: `Ctrl+Alt+P`)으로 재지정할 수 있습니다.

### 4.2 개발 빌드 보안 경고 (SmartScreen / Gatekeeper)
- 공식 유료 코드 서명 인증서가 발급되지 않은 초기 배포본의 경우 OS의 보안 경고가 나타납니다.
  - Windows: "SmartScreen 인식할 수 없는 앱" -> [추가 정보] -> [실행]
  - macOS: "열 수 없습니다" -> 터미널 `xattr -cr` 또는 [시스템 설정 -> 확인 없이 열기]

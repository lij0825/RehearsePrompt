# RehearsePrompt Windows 설치 가이드 (일반 사용자용)

이 문서는 컴퓨터에 익숙하지 않은 일반 사용자도 Windows PC에서 **RehearsePrompt**를 쉽고 안전하게 설치하고 실행할 수 있도록 안내합니다.

---

## 1. 나에게 맞는 설치 파일 선택하기

공식 배포 페이지에서 다음 파일 중 내 환경에 맞는 형식을 다운로드합니다:

| 파일 이름 | 추천 대상 | 특징 |
| :--- | :--- | :--- |
| **`RehearsePrompt-1.0.0-Windows-x64-setup.exe`** | **일반 개인 사용자 (가장 추천)** | 바탕화면/시작메뉴 바로가기가 자동 생성되며, 제어판에서 쉽게 삭제 가능한 표준 설치 프로그램 |
| **`RehearsePrompt-1.0.0-Windows-x64-portable.exe`** | **USB 휴대 사용자, 공용 PC** | 별도 설치 과정 없이 더블 클릭만으로 즉시 실행되는 무설치 포터블 파일 |
| **`RehearsePrompt-1.0.0-Windows-x64.msi`** | **회사/학교 전산 관리자** | Active Directory 및 그룹 정책(GPO) 대량 배포용 엔터프라이즈 패키지 |

---

## 2. 단계별 설치 방법

### 1단계: 설치 프로그램 실행
다운로드한 `RehearsePrompt-1.0.0-Windows-x64-setup.exe` 파일을 더블 클릭합니다.

### 2단계: Windows SmartScreen 파란색 경고창 대처 방법
설치 파일을 처음 실행하면 다음과 같이 **"Windows의 PC 보호"**라는 파란색 화면이 나타날 수 있습니다.

![Windows SmartScreen 추가 정보 클릭 화면](images/windows-smartscreen-more-info.png)

> **⚠️ 왜 이런 경고가 나타나나요?**  
> RehearsePrompt는 비영리 목적으로 제작된 순수 연습용 오픈소스 프로그램입니다.  
> 마이크로소프트는 수백만 원에 달하는 고가의 유료 기업 인증서(EV 인증서)로 서명되지 않은 신규 배포 프로그램에 대해 기본적으로 이 안내창을 표시합니다.  
> **프로그램에 악성코드나 바이러스가 있어서 뜨는 경고가 아니므로 안심하셔도 됩니다.**

**해결 방법 (실행하기)**:
1. 안내창 본문 왼쪽의 작은 밑줄 글씨인 **`[추가 정보]`**를 클릭합니다.
2. 창 하단에 새롭게 나타나는 **`[실행]`** 버튼을 클릭합니다.

![Windows SmartScreen 실행 버튼 클릭 화면](images/windows-smartscreen-run-anyway.png)

### 3단계: 설치 마법사 진행
설치 마법사가 열리면 안내에 따라 **`[다음]`** 버튼을 누릅니다.  
기본 설치 경로(`C:\Users\사용자명\AppData\Local\Programs\rehearse-prompt`)에 파일이 자동으로 설치되며, 바탕화면과 시작 메뉴에 아이콘이 생성됩니다.

![Windows 설치 마법사 진행 화면](images/windows-installer-wizard.png)

### 4단계: 설치 완료 및 실행
설치가 끝나면 **`[마침]`** 버튼을 누르면 RehearsePrompt가 자동으로 시작됩니다.

---

## 3. 마이크 권한 설정 (음성 인식 사용 시 필수)

음성 인식 기반 자동 스크롤 기능을 사용하려면 Windows 시스템에서 마이크 권한을 허용해야 합니다.

![Windows 마이크 권한 설정 화면](images/windows-microphone-permission.png)

1. 키보드의 **`Windows 키 + I`**를 눌러 **[설정]** 창을 엽니다.
2. 왼쪽 메뉴에서 **[개인 정보 및 보안]** > **[마이크]**를 선택합니다.
3. 다음 두 항목이 모두 **`[켬]`**으로 설정되어 있는지 확인합니다:
   - **마이크 액세스**: `켬`
   - **데스크톱 앱이 마이크에 액세스하도록 허용**: `켬`
4. RehearsePrompt 앱 목록에서 마이크 허용이 활성화되어 있는지 확인합니다.

---

## 4. 앱 업데이트 및 삭제(제거) 방법

### 앱 업데이트
새로운 버전의 설치 파일(`setup.exe`)을 다운로드하여 기존 앱을 삭제할 필요 없이 그대로 실행하시면 기존 대본 데이터를 유지한 채 최신 버전으로 자동 업데이트됩니다.

### 앱 삭제(제거)
더 이상 앱을 사용하지 않을 경우 언제든 깔끔하게 삭제할 수 있습니다:
1. Windows **[시작]** 버튼 우클릭 > **[설치된 앱]** (또는 제어판 > 프로그램 추가/제거)으로 이동합니다.
2. 목록에서 **`RehearsePrompt`**를 찾아 우측의 점 세 개 메뉴(`...`)를 클릭한 뒤 **`[제거]`**를 선택합니다.
3. 안내창에 따라 진행하면 프로그램과 바로가기가 시스템에서 완전히 삭제됩니다.

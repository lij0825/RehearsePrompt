# RehearsePrompt Windows 설치 가이드

이 문서는 Windows 환경에서 **RehearsePrompt**를 안전하고 올바르게 설치, 점검, 제거할 수 있도록 상세히 안내합니다.

---

## 지원 환경

- **지원 Windows 버전**: Windows 10 (64비트, 버전 1809 이상), Windows 11
- **지원 아키텍처**: x86_64 (64비트 Intel / AMD 프로세서).  
  *(ARM64 기기인 Snapdragon 탑재 노트북의 경우 Windows 11의 Prism x64 에뮬레이션을 통해 구동 가능합니다.)*
- **필요한 WebView2**: **별도 설치 불필요**.  
  RehearsePrompt는 자체 독립 Chromium 엔진을 내장하고 있으므로, Windows 시스템에 WebView2 런타임이 설치되어 있지 않아도 독립적으로 정상 실행됩니다.
- **필요한 저장 공간**: 최소 **300 MB 이상의 여유 디스크 공간**  
  - 다운로드 설치 파일: 약 85 MB
  - 설치 후 프로그램 바이너리: 약 250 MB
  - 대본 데이터 저장 공간: 약 수 MB (사용자 작성량에 따름)
- **인터넷 필요 여부**: **인터넷 연결 불필요 (100% 오프라인 지원)**  
  설치 과정 및 앱 실행, 대본 작성, 텔레프롬프터 기능 모두 오프라인 환경에서 완벽하게 동작합니다.
- **관리자 권한 필요 여부**:
  - 기본 `.exe` (NSIS) 설치 프로그램: **관리자 권한 불필요** (현재 사용자 계정 전용 폴더에 안전하게 설치)
  - `.msi` 엔터프라이즈 패키지: **관리자 권한 필요** (시스템 전체 `Program Files` 배포용)

---

## 설치 파일 종류

| 파일 | 설명 | 추천 대상 |
|---|---|---|
| **.exe** | 일반 사용자가 설치하기 쉬운 NSIS 설치 파일 (`RehearsePrompt-1.0.0-Windows-x64-setup.exe`) | **대부분의 사용자** |
| **.msi** | 조직·관리자·배포 시스템용 (`RehearsePrompt-1.0.0-Windows-x64.msi`) | **기업·IT 관리자** |

> **참고 (포터블 실행 파일)**:  
> 설치 과정 없이 USB 등에서 바로 실행하고자 하는 경우 `RehearsePrompt-1.0.0-Windows-x64-portable.exe` 파일을 사용할 수 있습니다.

## 설치 전 확인

1. **기존 앱 종료**:  
   이전 버전의 RehearsePrompt가 실행 중이라면 작업표시줄에서 앱을 완전히 종료하십시오.
2. **중요한 대본 백업**:  
   기존 사용자의 경우 앱 설정 메뉴의 **`[대본 전체 내보내기(JSON)]`**를 통해 작성한 대본을 안전한 위치에 백업하십시오.
3. **다운로드한 파일의 출처 확인**:  
   반드시 공식 GitHub 저장소(Releases 탭) 또는 공식 배포처에서 다운로드했는지 웹 브라우저 주소를 확인하십시오.
4. **파일 해시 확인 방법**:  
   다운로드한 파일이 변조되지 않았는지 확인하려면 PowerShell을 열고 다음 명령어를 실행하여 공식 체크섬(`SHA256SUMS.txt`)과 일치하는지 대조하십시오:
   ```powershell
   Get-FileHash -Algorithm SHA256 .\RehearsePrompt-1.0.0-Windows-x64-setup.exe
   ```
5. **바이러스 검사**:  
   설치 전 Windows Defender 또는 사용 중인 백신 프로그램으로 다운로드한 파일의 보안 상태를 검사하십시오.

## 설치 절차

### 1. 설치 파일 실행
다운로드한 설치 파일(`.exe`)을 더블 클릭하여 실행합니다.

![Windows 설치 마법사 시작 화면](images/windows-installer-step-01.png)

### 2. Windows 보안 경고가 나타날 수 있는 이유
설치 파일을 실행할 때 Windows SmartScreen 보호 화면이 나타날 수 있습니다. 이는 RehearsePrompt가 고가의 기업용 유료 EV 인증서로 서명되지 않은 오픈소스/개발 빌드인 경우 운영체제가 신규 배포 파일을 자동으로 식별하여 띄우는 정상적인 알림입니다. 상세한 대처 방법은 하단의 [미서명 파일 경고](#미서명-파일-경고) 절을 반드시 확인하십시오.

### 3. 설치 경로 확인
기본 설치 경로는 다음과 같이 사용자 계정 로컬 폴더로 지정됩니다:  
`C:\Users\<사용자명>\AppData\Local\Programs\rehearse-prompt`  
관리자 권한 없이도 안전하게 설치되며 다른 프로그램과 충돌하지 않습니다.

### 4. 바로가기 선택
바탕화면 바로가기 및 시작 메뉴 바로가기 생성 옵션이 기본적으로 활성화되어 있습니다.

### 5. 설치 완료
파일 복사가 완료되면 설치 마법사가 성공 메시지를 표시합니다.

![Windows 설치 완료 화면](images/windows-installer-finish.png)

### 6. 앱 시작
"RehearsePrompt 실행" 체크박스를 확인하고 **`[마침]`** 버튼을 누르면 프로그램이 시작됩니다.

### 7. 첫 실행 온보딩
앱이 시작되면 화면에 기본 준비된 예시 대본이 표시됩니다. 상단 도구 모음과 텔레프롬프터 진입 버튼의 위치를 둘러보십시오.

## 설치 후 확인

설치가 올바르게 완료되었는지 다음 항목들을 점검하십시오:

- **시작 메뉴**: Windows 시작 메뉴의 앱 목록 또는 최근 추가된 앱에 **RehearsePrompt**가 등록되어 있는지 확인합니다.
- **바탕화면 바로가기**: 바탕화면에 RehearsePrompt 아이콘이 정상 생성되었는지 확인합니다.
- **앱 버전**: 앱 내부 설정 화면 또는 실행 파일 속성에서 버전이 **v1.0.0**으로 표시되는지 확인합니다.
- **새 스크립트 생성**: 왼쪽 상단의 `[+ 새 대본 작성]`을 클릭하여 새 문서 작성이 가능한지 확인합니다.
- **저장**: 제목과 본문을 입력한 뒤 하단 `[저장]` 버튼이 정상 작동하는지 확인합니다.
- **앱 재실행**: 앱을 종료했다가 다시 실행하여 방금 작성한 대본이 온전히 남아 있는지 확인합니다.
- **마이크 권한**: 프롬프터 모드에서 마이크 아이콘을 켰을 때 Windows 설정의 마이크 권한이 정상 허용되는지 확인합니다.
- **카메라 권한**: 카메라 미리보기 스위치를 켰을 때 웹캠 화면이 정상적으로 표출되는지 확인합니다.

## 제거 방법

앱이 더 이상 필요하지 않을 경우 다음 방법으로 언제든 시스템에서 제거할 수 있습니다:

### 설정 > 앱 > 설치된 앱
1. Windows **[설정]**(`Win + I`) > **[앱]** > **[설치된 앱]**으로 이동합니다.
2. 목록에서 **`RehearsePrompt`**를 검색합니다.
3. 우측 메뉴(`...`)를 클릭하고 **`[제거]`**를 선택합니다.

![Windows 설정에서 앱 제거 화면](images/windows-uninstall-settings.png)

### 제어판
1. **[제어판]** > **[프로그램 및 기능]**으로 이동합니다.
2. 목록에서 **`RehearsePrompt`**를 찾아 더블 클릭하여 제거 마법사를 실행합니다.

### 앱 데이터 삭제 여부 및 백업 권장
- 표준 언인스톨러는 실행 바이너리와 바로가기를 깨끗하게 삭제하지만, 사용자가 작성한 소중한 대본 데이터(`%APPDATA%\rehearse-prompt`)는 실수로 인한 유실을 방지하기 위해 자동으로 보존됩니다.
- 대본 데이터까지 완전히 삭제하고자 하실 경우, **반드시 필요한 대본을 JSON으로 백업한 후** 파일 탐색기에서 해당 폴더(`%APPDATA%\rehearse-prompt`)를 수동으로 삭제하십시오.

## 미서명 파일 경고

서명되지 않은 개발용 빌드에서는 Windows SmartScreen이 다음과 같은 경고 화면을 표시할 수 있습니다:

![Windows SmartScreen 경고 화면](images/windows-smartscreen-warning.png)

> **⚠️ 보안 주의사항**  
> 보안 경고를 맹목적으로 무시하고 실행하는 것은 위험할 수 있습니다.  
> 반드시 다음 안전 지침을 확인한 후에만 진행하십시오:

- **공식 배포 경로인지 확인**:  
  다운로드한 웹사이트가 공식 RehearsePrompt GitHub 리포지토리인지 다시 한번 확인하십시오.
- **파일 해시 확인**:  
  다운로드한 파일의 SHA-256 해시값을 측정하여 릴리스 공지에 게시된 공식 해시값(`793C9E183504584759A1FEDBDD3BB9D01C0DFD526B994C5BB42FA5192A77776B`)과 100% 일치하는지 대조하십시오.
- **개발 빌드인지 확인**:  
  현재 사용하려는 파일이 비영리 오픈소스 개발 빌드(Unsigned Test Build)로 배포된 것인지 확인하십시오.
- **회사 컴퓨터에서는 관리자에게 문의**:  
  사내 보안 정책이 적용된 업무용 PC인 경우, 임의로 실행하지 마시고 사내 IT 보안 관리자에게 설치 허용 여부를 문의하십시오.
- **출처가 불명확하면 실행하지 않기**:  
  이메일 첨부파일, 블로그, 비공식 자료실 등 출처가 불분명한 경로에서 받은 파일은 **절대로 실행하지 마시고 즉시 삭제**하십시오.

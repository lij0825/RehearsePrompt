# RehearsePrompt - 제품 요구사항 정의서 (PRD)

> 문서 버전: 1.0.0  
> 최종 수정일: 2026-09-10  
> 상태: 초기 검토 및 승인 대기

## 1. 제품 개요 및 목적

**RehearsePrompt**는 Windows와 macOS에서 실행되는 **모의 면접 및 발표 연습용 텔레프롬프터 데스크톱 애플리케이션**입니다.

### 1.1 핵심 목적
- **모의 면접 답변 연습**: 실제 면접 질문에 맞추어 답변 구조를 다듬고 자연스럽게 말하는 훈련.
- **발표 대본 연습**: 프레젠테이션, 피칭 대본의 전달 속도(WPM)와 호흡을 조절하는 연습.
- **영상 촬영 및 녹화 연습**: 카메라 렌즈 방향을 바라보며 대본의 흐름을 놓치지 않는 시선 훈련.
- **온라인 모의 면접**: 화상 회의 화면 옆에 배치하여 카메라 아이콘택트 유지 훈련.
- **자기소개 및 프로젝트 설명 연습**: 엘리베이터 피치와 핵심 키워드 중심의 발표 숙달.

### 1.2 비목적 (Non-Goals & Anti-Cheat Compliance)
본 제품은 **부정행위나 은닉을 목적으로 하지 않으며, 윤리적 기준과 공정 평가 규정을 철저히 준수**합니다. 다음 기능은 의도적으로 배제하며 기술적으로 차단합니다:
- **화면 공유 숨김 기능 배제**: Zoom, Google Meet, MS Teams, 디스코드, 웹 브라우저 등의 화면 공유나 화면 캡처 시 창을 몰래 숨기는 기능(`SetWindowDisplayAffinity`, `WDA_EXCLUDEFROMCAPTURE`, `NSWindow.sharingType = .none` 등)을 일체 사용하지 않습니다.
- **감독/안티치트 회피 배제**: 온라인 시험 감독 시스템, 프로세스 모니터링, 키보드/마우스 입력 감시를 우회하거나 조작하지 않습니다.
- **비인가 오버레이 및 백그라운드 수집 배제**: 사용자가 인지하지 못하는 백그라운드 녹음, 비공개 오버레이 창, 화면 녹화 감시 우회를 구현하지 않습니다.
- **실시간 AI 부정 답변 생성 배제**: 면접관 질문을 실시간 청취하여 자동으로 답변을 생성하는 기능을 제공하지 않습니다.
- **원격 자동 전송 배제**: 사용자의 대본과 음성은 100% 로컬 기기에만 저장되며 외부 서버로 무단 전송되지 않습니다.
- **화면 공유 투명성 고지**: 화면 공유 시 프롬프터 창이 상대방에게 그대로 보일 수 있음을 UI 상단에 명확하게 안내합니다.

## 2. 사용자 페르소나 및 핵심 시나리오

1. **취업/이직 준비생 (면접 준비)**
   - 1분 자기소개와 프로젝트 경험 대본을 작성하고, 목표 시간(60초)에 맞춰 적정 속도(130 WPM)로 읽는 연습을 수행.
   - 웹캠 프리뷰를 켜고 렌즈 근처에 프롬프터를 배치하여 카메라 시선 처리 개선.
2. **기술 발표자 / 컨퍼런스 스피커**
   - 발표 슬라이드 전환 타이밍과 대본 문단 구분을 매칭하여 리허설.
   - 글로벌 단축키로 PPT 슬라이드 쇼 중에도 프롬프터 스크롤 속도를 조절.
3. **콘텐츠 크리에이터 / 교육 강사**
   - 긴 대본을 음성 인식 기반 자동 스크롤로 읽으며 자연스러운 촬영 진행.

## 3. 핵심 기능 요구사항 명세

### A. 스크립트 관리
- 스크립트 생성, 수정, 복제, 삭제(휴지통 및 복구 지원), 상세 조회.
- 메타데이터: ID, 제목, 설명, 본문, 태그 목록, 즐겨찾기(`isFavorite`), 생성일시, 수정일시, 마지막 열람일시, 예상 소요시간, 글자/단어 수, 언어, 버전(최대 10개 스냅샷), 삭제일시(`deletedAt`).
- 정렬: 최근 수정순, 생성일순, 제목순(가나다/ABC), 즐겨찾기 우선 필터.
- 검색: 제목, 본문, 태그를 대상으로 하는 실시간 로컬 인덱싱 검색.
- 저장 정책: 입력 중단 후 800ms 디바운스 자동 저장, 수동 저장(`Ctrl+S`/`Cmd+S`), 변경 추적(Dirty 플래그), 앱 종료 전 미저장 변경 확인 모달.

### B. 텍스트 편집기
- 줄바꿈 및 문단 구조를 원형 그대로 보존하는 클린 텍스트 에디터.
- Undo/Redo(`Ctrl+Z`, `Ctrl+Y`/`Cmd+Shift+Z`), 찾기/바꾸기(`Ctrl+F`, `Ctrl+H`).
- 실시간 통계: 단어 수, 공백 포함/제외 글자 수, WPM 기반 예상 낭독 시간.
- 문장 및 문단 단위 파싱 (한국어 종결 어미 및 영어 구두점 기준 정밀 파싱).
- 가져오기/내보내기: TXT, Markdown(.md), JSON 백업 파일(.json).

### C. 텔레프롬프터 모드
- 전체 스크립트 디스플레이 및 집중 읽기 뷰.
- 현재 읽는 문단 및 문장 하이라이트(토스 블루 포인트 배경/폰트 강조).
- 진행률 게이지, 경과 시간, 잔여 예상 시간, 현재 WPM 표시.
- 시작 전 3초/5초 카운트다운 오버레이 및 완료 상태 뷰.
- 입력 제어: 스페이스바(재생/일시정지), 상하 방향키/마우스 휠(스크롤), Home/End, `[` / `]` (속도 증감).

### D. 3대 스크롤 엔진
1. **일정 속도 자동 스크롤 (Constant Speed Auto-Scroll)**:
   - 60 ~ 240 WPM (기본값 130 WPM), 5단위 미세 조정.
   - `requestAnimationFrame` 기반 부드러운 서브픽셀 보간 스크롤 (속도 전환 시 점프 방지 댐핑 필터 적용).
2. **음성 인식 기반 스크롤 (Voice-Guided Scroll)**:
   - Web Speech API 및 로컬 음성 엔진 추상화 계층(`SpeechRecognitionService`).
   - 발화 텍스트와 대본의 편집 거리(Levenshtein) 및 n-gram 어절 매칭을 통한 현재 읽는 위치 자동 트래킹.
   - 발화 중단 시 자동 일시정지, 인식 오류 시 수동 스크롤 즉각 오버라이드.
   - 마이크 음량(Level Meter) 실시간 시각화, 마이크 미연결/권한 거부 대응.
3. **수동 스크롤 (Manual Scroll)**:
   - 마우스 휠, 트랙패드, 키보드(PageUp/Down, Up/Down) 완벽 지원.

### E. 연습 세션 및 통계 분석
- 세션 메타데이터: ID, 대본 ID, 시작/종료 일시, 총 소요시간, 스크롤 모드, 평균 WPM, 완독률(%), 일시정지 횟수, 마이크 사용 여부, 세션 메모, 완독 여부.
- 세션 종료 후 리포트 카드: 이전 세션 대비 속도 비교, 완독 달성률, 사용자 메모 저장.
- 세션 이력 JSON/CSV 내보내기 지원.

### F. 카메라 및 아이콘택트 가이드 (선택 기능)
- 카메라 권한 사용 전 명확한 사전 고지 및 동의 팝업.
- 원본 영상 절대 저장/업로드 금지 (로컬 캔버스/비디오 엘리먼트 렌더링 전용).
- 웹캠 미리보기 On/Off 토글, 카메라 미보유/권한 거부 시에도 프롬프터 정상 작동.
- 렌즈 응시선 가이드: 카메라 위치(상단 중앙 등) 근처로 시선을 유도하는 가이드 라인 및 가이드 배지 제공.

### G. 글로벌 단축키 (Global Shortcuts)
- 앱 비활성(백그라운드) 상태에서도 작동:
  - 시작/일시정지: `CommandOrControl+Shift+Space`
  - 다음 문단: `CommandOrControl+Shift+Down`
  - 이전 문단: `CommandOrControl+Shift+Up`
  - 속도 증가: `CommandOrControl+Shift+]`
  - 속도 감소: `CommandOrControl+Shift+[`
  - 처음으로 리셋: `CommandOrControl+Shift+Home`
- 단축키 충돌 감지, 등록 실패 시 사용자 안내 및 대체 키 매핑 커스텀 설정 UI 제공.

### H. 창 모드 및 디스플레이 제어
- 일반 편집 모드, 텔레프롬프터 읽기 모드, 컴팩트 플로팅 모드(최소 너비 지원), 전체 화면(`F11`).
- 항상 위에 표시(`Always on Top`) 토글 버튼 및 상태 표시.
- 불투명도(Opacity) 50% ~ 100% 슬라이더 제어 (기본값 100% 불투명).
- 창 위치(x, y), 크기(width, height), 모드 상태 로컬 영구 복원.
- **화면 캡처 방지 API 절대 배제**: OS 표준 창으로 렌더링.

### I. 설정 및 데이터 관리
- 일반: 시작 시 마지막 스크립트 열기, 자동 저장 주기(500~2000ms), 테마(라이트/다크), 언어(한국어/영어).
- 프롬프터: 기본 WPM, 폰트 크기(18~48px), 줄간격(1.4~2.2), 여백, 가로폭, 문장/문단 하이라이트 여부, 카운트다운 시간.
- 개인정보 및 데이터: 로컬 데이터 폴더 즉시 열기, 전체 데이터 초기화(2단계 확인 모달), 외부 네트워크 통신 목록 공개.

### J. 온보딩 (5단계 안내 튜토리얼)
- 1단계: RehearsePrompt 소개 및 연습 목적 안내
- 2단계: 대본 작성 및 WPM 속도 조절 방법
- 3단계: 텔레프롬프터 조작법 및 단축키
- 4단계: 마이크/카메라 권한의 선택적 사용 및 개인정보 로컬 원칙 안내
- 5단계: 화면 공유 시 투명성 주의사항 (창이 화면 공유에 노출됨을 공지)
- 도움말 메뉴를 통해 언제든지 재열람 가능.

## 4. UI/UX 디자인 시스템 규약 (design.md 준수)
- **토스 디자인 시스템(TDS)** 철학 반영:
  - 색상: Toss Blue (`#3182F6` / `oklch(0.624 0.176 254)`), 차가운 그레이스케일(`grey-900` ~ `grey-50`), 흰색 캔버스.
  - 타이포그래피: Pretendard 기반 Type Ramp (H1~H4, Title-1~2, Body-1~3, Label-L~S, Caption), 숫자 표기 tabular-nums.
  - 버튼 규격: XL(56px, R16), L(48px, R14), M(40px, R12), S(32px, R10).
  - 어조: 친절하고 명확한 대화형 존댓말 **해요체** ("저장했어요", "스크립트를 복사했어요", 에러 시 "네트워크 연결을 확인해 주세요").
